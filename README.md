# Ferramas

Proyecto web de ferretería desarrollado con HTML, CSS, JavaScript, Node.js, Express y MySQL.

## Funciones principales

- Registro e inicio de sesión
- Carrito de compras
- Integración con Mercado Pago
- Suscripción por correo con Gmail
- Sistema de productos
- Diseño responsive
- Perfil de usuario
- Categorías de productos

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Node.js
- Express
- MySQL
- Mercado Pago SDK
- Nodemailer

## Instalación

### Backend

Entrar a la carpeta:

```bash
cd ferramas-api
```

Instalar dependencias:

```bash
npm install
```

Iniciar servidor:

```bash
node src/app.js
```

### Frontend

Abrir la carpeta `ferramas-front` con Live Server en Visual Studio Code.
